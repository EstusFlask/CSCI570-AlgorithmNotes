# CSCI570 Algorithm Notes

A personal fork of [Julius-JiahaoLiu/CSCI570-AlgorithmNotes](https://github.com/Julius-JiahaoLiu/CSCI570-AlgorithmNotes), containing notes and homework for USC CSCI-570, Analysis of Algorithms, Spring 2024, instructed by Shahriar Shamsian.

USC CSCI-570 2024 春季算法课程笔记与作业的个人 fork，保留上游资料及其来源。

## Contents

- [`LectureNotes/`](LectureNotes/): algorithm lecture notes in PDF format.
- [`Homework/`](Homework/): homework documents in PDF format.

Topics include divide and conquer, dynamic programming, greedy algorithms, graph algorithms, network flow, complexity, and approximation algorithms. These are course materials, not a runnable software project.
